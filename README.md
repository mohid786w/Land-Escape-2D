# Land-Escape-2D
Objective: The goal is to finish each level as fast as you can while dodging obstacles and gathering power ups. 
 
Game Mechanics: 

Game Controls: 

Left Arrow/ A = Left Movement  

Right Arrow / B = Right Movement 

Up Arrow / W = Jump 

Holding space = Attack 

Escape Button = Pause Menu 
 
Health System: 

Health features are shared between players and adversaries. 
To regain health, gather health. 

Power-ups: 

Coins: These are used for points in Power-Ups. 

Health Power up: Restores player health 

Jumper Power up: The player gets three hops. 

Level Design:  
Players move through a number of levels, each with its own set of obstacles, opponents, and difficulties. 

Timer:  
The timer begins when the level starts and ends when the game is finished. 

Leaderboard: 
The top three scores based in completion times are shown on the leaderboard.
